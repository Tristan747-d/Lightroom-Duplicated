# al-dedupe 实验记录（2026-10-27）

目标：重写重复检测，解决 v1 的误并、无判别力、慢三大问题。
所有结论都来自真实目录 `Lightroom Catalog.lrcat`（1469 张）的实验，不是拍脑袋。

## 实验脚本

| 脚本 | 目的 | 关键结论 |
|---|---|---|
| `harness.py` | 缓存「目录→预览路径」，把每轮实验从 60s 扫盘降到 0.2s | 全库 os.walk 一次建索引 |
| `exp1.py` | 对比 8/12/16×16 dHash 对已知样本的距离 | 8×8 对低结构图完全失效 |
| `exp3.py` | 用文件名 GT 标定阈值 | **GT 本身无效**（相机计数器重置导致重名不同图）→ 弃用 |
| `exp6.py` | 结构加权 4×4 区域哈希 | 真连拍 0.62–0.79 vs 假配对 0.57–0.69，需时间窗裁决 |
| `exp7.py` | synthetic 变体（重压缩/缩放/±5%亮度/裁剪2%）标定 | **dHash8 真 0–7 vs 假 16–44；hist64 真 ≤0.23 vs 假 ≥0.23** |

## 关键发现

### 1. 8×8 dHash 无判别力
Synthetic 变体上可分，但全库扫描时"低结构图"大量碰撞：

```
_TSY5132-2.JPG(2025-08-01 河船) vs DSC_0218-2.JPG(2025-10-03 跑道)  dist=2
DSC_0218 vs DSC_0301(相隔11小时)                                     dist=5
```

64bit 全局梯度哈希本质是"地平线位置 + 明暗布局"，不是图像内容。

### 2. 传递闭包误并
v1 用并查集，A~B、B~C ⇒ A~C 同组。实测产生 24 张、跨 16 小时、
组内 sim 低到 0.42 的巨型伪组。

### 3. 文件名 GT 无效（重要陷阱）
`_TSY6444-2.JPG`（河船）与 `_TSY6444.JPG`（跑道运动员）是**完全不同的照片**——
相机文件计数器跨会话重置。本目录 12 个文件名对应 24 张不同照片。
任何基于文件名的分组/去重都会标错对象。

### 4. 空白帧是"黑洞"
`DSC_0945-2.JPG` 预览只有 777 字节（纯黑），梯度能量≈0，
其哈希与 12 张不同照片"匹配"。→ 能量门控。

### 5. 真连拍确实难
`_TSY5999/_TSY5998`（0.1s 间隔、同一跳跃、主体移位）：
结构加权相似度仅 0.70，与跨场景假配对的 0.68 几乎重叠。
**结论：连拍判定必须靠时间窗做最终裁决，纯视觉不可分。**

## 最终方案（已落地 tools/al-dedupe）

```
exact:  hist64 L1/2 ≤ 0.12  且  dHash8 ≤ 8
        （synthetic 标定：召回 98%，负样本误判 0.00%）
burst:  结构加权 4×4 区域 sim ≥ 0.55  且  时间连续（间隔≤15s，段总跨度≤60s）
门控:   梯度能量 ≥ 3.0（排除空白/死黑帧）
分组:   exact 要求完全子图 + 时间跨度 ≤ 6h
        burst 用时间连续 run（非传递闭包）
```

## 追加发现（连拍档的判别力极限）

用「帧号相邻 & Δt≤2s」作为真连拍代理标签，量化纯哈希的连拍判别力：

```
确定连拍 n=213: patch_sim p50=0.519
其他窗内对 n=1669: patch_sim p50=0.510     ← 完全重合
阈值 0.55: 召回29% 误判12.1% 精度≈23%
```

全库 ~100 万对里，纯随机就有 ~7.5 万对超过 0.55。**结构哈希对"同场景
不同瞬间"根本没有判别力**，阈值落在噪声底。

改用 al-vision 语义标签裁决（只对候选对调用，0.16s/张）：

```
真连拍 mean=0.706 vs 非连拍 0.550，精度提升到 ~67%
```

**但语义不能一票否决**：`_TSY7978/7979` 是真连拍（Δt=0.1s, sim=0.789），
Vision 却把一张标成 outdoor/foliage、另一张标成 health_club/interior，
一致度仅 0.49。硬阈值会错杀最强证据。
→ 最终改为加权合成（哈希0.5 + 语义0.5, 阈值0.63）：Vision 误判时高 sim
仍能兜住；纯随机对两者都低被挡。实测 8 个已知真连拍保留 7 个。

另：`grid-RGB` 颜色布局描述子同样弱（49%召回/14.7%误判），已否决。
